# Changelog

## 2.0.0 — 2026-07-29

- Rebuilt the compact state-machine prototype as a full-stack control plane.
- Added React operations console and responsive visual system.
- Added JWT authentication and three API-enforced roles.
- Added projects, datasets, experiments, models, workers, jobs, metrics, alerts,
  and audit events.
- Added priority scheduling, resource-aware worker assignment, future scheduling,
  cancellation, automatic retry policy, and server-sent events.
- Added embedded PostgreSQL-compatible demo mode and PostgreSQL Docker deployment.
- Added 20 automated tests, strict TypeScript, production builds, and CI.
- Added architecture, API, interview, security, and upload documentation.
